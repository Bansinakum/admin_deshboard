# Project 3 — Admin Dashboard (React + Bootstrap)

## Requirements
- Node.js 18+ and npm

## Run locally
```bash
npm install
npm run dev
```
Open the local URL printed by Vite (usually http://localhost:5173).

## Included
- Admin sidebar and responsive layout
- KPI cards for donors, requests, blood stock and pending approvals
- Donation activity chart built with CSS
- Blood stock levels by blood group
- Searchable requests table
- Approve/reject actions update demo state

Note: This is a front-end demo using sample data. It is not connected to a real database, backend, authentication, or blood inventory service.
